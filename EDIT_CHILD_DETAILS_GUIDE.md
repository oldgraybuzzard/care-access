# Edit Child Details Guide

## 🎯 Overview

You can now **edit ALL child information** including medical, behavioral, education, family, and personal details through a comprehensive 6-step edit wizard.

---

## 📝 How to Edit Child Information

### Method 1: From Child Profile (Recommended)

1. **Open Child Profile**
   - Go to Children list
   - Tap on any child to view their profile

2. **Tap Edit Button**
   - Look for the **Edit icon** (✏️) in the top-right corner of the profile
   - Tap it to open the comprehensive edit form

3. **Edit Information**
   - Navigate through 6 steps:
     - **Step 1**: Basic Information (name, DOB, gender, etc.)
     - **Step 2**: Referral Information
     - **Step 3**: Status & Legal
     - **Step 4**: Medical Information
     - **Step 5**: Behavioral & Trauma
     - **Step 6**: Personal Information
   
4. **Save Changes**
   - Use "Continue" to move forward through steps
   - Use "Back" to go to previous steps
   - Tap "Save" on the final step to update the child

---

## 🆚 Edit vs. Quick Add vs. Full Intake

| Feature | Quick Add | Full Intake | Edit Child |
|---------|-----------|-------------|------------|
| **Purpose** | Create new child | Create new child | Update existing child |
| **Fields** | Basic only | All fields | All fields |
| **Steps** | Single form | 6 steps | 6 steps |
| **Pre-filled** | ❌ | ❌ | ✅ All existing data |
| **Use Case** | Quick entry | Complete onboarding | Update details |

## 💡 Tips

### Comma-Separated Lists
For fields like medications, allergies, interests, etc., enter items separated by commas:
```
Example: Aspirin, Ibuprofen, Vitamin D
```

### Navigation
- **Continue**: Moves to next step
- **Back**: Returns to previous step
- **Save**: Saves all changes (only on final step)

### Data Preservation
- All existing data is pre-filled in the form
- If you don't change a field, it keeps its current value
- Empty fields remain empty unless you add data

### Validation
- Required fields are marked with *
- You must fill required fields to save
- The form validates data before saving
